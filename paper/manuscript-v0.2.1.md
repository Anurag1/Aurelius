# Aurelius v0.2.1: A Reproducible Synthetic Benchmark and Optional External-Baseline Adapter for Profile-Aware Audio Processing

**Manuscript status:** Software/methods draft. Not peer reviewed. No clinical or human-subject experiment is reported.

## Abstract

Profile-aware audio processing is an established research area spanning consumer hearables, open-source master-hearing-aid platforms, and auditory-model-in-the-loop machine learning. This paper presents Aurelius v0.2.1, a deterministic Python benchmark for inspecting reference audio-processing algorithms under synthetic frequency-dependent attenuation and additive noise. The internal benchmark compares an identity baseline, fixed capped profile equalization, and a Wiener-style processor supplied with an independent noise-only reference. The package provides validated synthetic profiles, deterministic signal generation, SNR and scale-invariant signal-to-distortion ratio (SI-SDR) metrics, raw per-trial CSV output, grouped JSON summaries, tests, and a protocol. An optional adapter invokes the official openMHA Breithaupt-2008 single-channel noise-reduction reference through the MHAIOFile static-file interface. The adapter contract is tested with a stub executable, but the real engine was unavailable and no openMHA performance result is claimed. Differentiable Auditory Loop (DAL) is reviewed using its published method; its source code was not independently executed. The work does not introduce a new clinical algorithm or biological auditory model. The synthetic results establish software behaviour only, not speech intelligibility, hearing benefit, safety, or clinical efficacy.

## 1. Introduction

A frequency-dependent gain profile is not a novel hearing-assistance concept. openMHA provides an established open research framework, consumer hearables include personalized hearing-assistance features, and recent work uses differentiable auditory models with neural audio processors. The original Aurelius prototype did not have calibrated acoustic output, clinical audiometry, a controlled benchmark, or validated intelligibility measures. The v0.2.1 release narrows the goal to a reproducible engineering benchmark and an optional adapter to one external signal-processing reference.

## 2. Methods

### 2.1 Synthetic profiles and probe

A profile contains frequency anchors and non-negative attenuation magnitudes for a synthetic channel. It is not an audiogram or physiological model. A seeded, amplitude-modulated harmonic probe and white-noise component are passed through the known synthetic channel. The probe is not recorded speech.

### 2.2 Internal reference algorithms

1. Identity: return the degraded mixture unchanged.
2. Fixed profile EQ: apply the inverse synthetic attenuation curve, capped at 12 dB.
3. Adaptive oracle Wiener-style processor: multiply profile compensation by a frequency-wise Wiener-style mask estimated using an independent noise-only reference generated by the simulator.

The third method is an oracle experiment because it receives information not ordinarily available in deployment. It is not a deployable noise estimator.

### 2.3 Optional openMHA adapter

The adapter targets openMHA v4.18.1's Breithaupt2008_SCNR reference chain (noise PSD estimation followed by cepstral smoothing) and uses the MHAIOFile static-file backend. The upstream reference declares two channels; the adapter duplicates the mono synthetic mixture to two identical channels, writes float32 WAV, runs the real mha binary, and checks exit status, output rate, channel count, sample count and finite values. It archives config, input/output WAVs, logs and SHA-256 metadata when the engine runs.

This selected method is a single-channel noise-reduction comparator, not a personalized fitting algorithm and not a full matched comparison with Aurelius profile EQ.

### 2.4 DAL comparison scope

DAL uses differentiable CARFAC auditory models, neural-activity-pattern and stabilized-auditory-image objectives, and a causal SEANet processor. Its reported dataset and auditory-representation metrics differ from Aurelius' synthetic probe and waveform SNR/SI-SDR. No numerical head-to-head comparison is valid from these different protocols. The paper's cited source repository returned HTTP 404 through the connected GitHub integration on 24 November 2026; no DAL code or checkpoint run is claimed.

### 2.5 Metrics and reproducibility

SNR and SI-SDR are computed against the known synthetic target over the active probe region. The nominal input SNR is set before the synthetic channel; the channel can change the effective signal/noise balance. Neither metric is a speech-intelligibility or human-benefit measure.

The benchmark records root seed, trial seeds, package versions and condition identifiers. The local suite covers profile validation, synthetic signal behaviour, repeatability, openMHA config generation, input validation, and file/command mechanics using a stub. A real-engine integration test is separately gated.

## 3. Internal synthetic results

A reference run used root seed 20261124, three profiles, nominal pre-channel SNRs of 0, 10 and 20 dB, and ten repeats per cell: 90 trials and 270 algorithm-level rows. The environment was Python 3.13.5, NumPy 2.3.5 and SciPy 1.17.0. Raw per-trial rows and a machine-readable summary are archived in artifacts/reference-run.

| Nominal pre-channel SNR | Identity SI-SDR mean ± SD (dB) | Fixed profile EQ mean ± SD (dB) | Adaptive oracle Wiener mean ± SD (dB) |
|---:|---:|---:|---:|
| 0 dB | 2.523 ± 5.770 | 0.170 ± 0.242 | 12.580 ± 0.151 |
| 10 dB | 11.562 ± 5.135 | 10.171 ± 0.251 | 19.598 ± 0.072 |
| 20 dB | 17.706 ± 3.078 | 20.168 ± 0.243 | 24.358 ± 0.042 |

The oracle method scores highest in this simulator, consistent with its access to an independent noise-only reference. This does not establish a deployable advantage. Fixed EQ does not dominate identity in the lowest-SNR condition, illustrating that inverse-profile gain may also amplify noise. These numbers are specific to the generated probe and simulator.

## 4. External baseline status

The openMHA adapter is implemented and passes stub-based contract tests. **The real openMHA engine was not executed** because no mha binary was installed in the Debian 13 workspace and outbound DNS/network access was unavailable for obtaining the official distribution. No openMHA result is included in the quantitative tables. The optional engine comparison remains a publication gate.

DAL was reviewed at the paper level only. Its published results are not reproduced here because the source code was not retrievable and its representation domain and methodology differ from Aurelius.

The local test suite completed with 13 tests passing and one optional real-openMHA integration test skipped. The GitHub-hosted CI attempt also failed before runner steps were allocated; the local result is the only verified test result for this milestone.

## 5. Limitations and conclusion

The synthetic probe is not recorded speech. The simulator is not a cochlear or hearing-loss model. There are no human participants, audiograms, calibrated acoustic measurements, or subjective tests. The gain cap is not a sound-pressure safety limit. Aurelius makes no diagnosis, treatment, benefit, comfort, or safety claim.

Aurelius v0.2.1 contributes an inspectable synthetic benchmark, explicit oracle/no-oracle assumptions, test coverage, machine-readable results, and an adapter contract for an existing openMHA reference. The external engine comparison and recorded-speech evaluation must be completed before a stronger empirical paper is submitted.
