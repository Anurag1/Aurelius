# Aurelius: A Reproducible Synthetic Benchmark for Profile-Aware Audio Compensation Pipelines

**Manuscript status:** Draft software/methods note. Not peer reviewed. The empirical scope is restricted to synthetic signal-fidelity experiments.

## Abstract

Personalized audio compensation is an active research area spanning conventional hearing-aid signal processing, open research toolkits, and auditory-model-in-the-loop machine learning. This paper presents Aurelius v0.2.0, a small, deterministic Python benchmark for inspecting the behaviour of profile-aware audio compensation algorithms under controlled synthetic channel attenuation and additive noise. The benchmark compares an identity baseline, fixed capped profile equalization, and a Wiener-style profile processor supplied with an independent noise-only reference. It provides validated synthetic profiles, deterministic signal generation, SNR and scale-invariant signal-to-distortion ratio (SI-SDR) metrics, raw per-trial CSV output, grouped JSON summaries, automated tests, and a documented protocol. The work does not introduce a new clinical hearing algorithm or biological auditory model. Its contribution is an inspectable test harness that makes its simulation assumptions—including the oracle noise-reference condition—explicit. Because the probe is synthetic and not recorded speech, results characterize software behaviour only and cannot establish speech intelligibility, hearing benefit, safety, or clinical efficacy.

**Keywords:** audio signal processing; reproducibility; synthetic benchmark; spectral equalization; Wiener filtering; software artifact.

## 1. Introduction

Personalized hearing-related signal processing is not a new problem. Consumer hearables now include self-fitting hearing-assistance features, openMHA provides an established open-source research environment, and recent research explores differentiable auditory models and neural processing in closed-loop optimization. These developments mean that a simple individualized frequency-gain curve is not a defensible novelty claim.

Aurelius began as a single-script prototype combining user-guided tone detection, a frequency-to-gain profile, and live microphone processing. That prototype did not include calibrated acoustic output, clinical audiometry, robust hearing-aid fitting, controlled evaluation, or a validated intelligibility measure. The present work deliberately narrows the goal: create a small reproducible harness that exposes the assumptions of three reference signal-processing paths under synthetic conditions.

## 2. Related work

The FDA authorized Apple's Hearing Aid Feature for compatible AirPods Pro software in September 2024 for adults with perceived mild-to-moderate hearing impairment; the agency described a multi-site study with 118 participants. openMHA is an open-source, hardware-independent platform for hearing-aid algorithm research and includes a substantial set of signal-processing components. The 2026 Differentiable Auditory Loop work combines a differentiable CARFAC cochlear model with neural audio processing and compares against master-hearing-aid baselines. A November 2026 review by Verhulst and colleagues surveys model-based personalized hearing-loss compensation and the relationship between precision diagnostics and algorithm personalization.

Aurelius v0.2.0 is not a substitute for any of these systems. It does not reproduce their algorithms. Its scope is a small and testable synthetic baseline harness for introductory experiments and software verification.

## 3. Methods

### 3.1 Synthetic profile model

A profile is a set of strictly increasing positive frequency anchors and non-negative attenuation magnitudes in dB. Values are interpolated on a log-frequency axis. The class is named SpectralLossProfile to distinguish a synthetic signal-channel transfer curve from an audiogram. Profile values are generated by the benchmark and are not measurements from human participants.

### 3.2 Signal generation

Each trial contains a deterministic, amplitude-modulated harmonic probe, a seeded independent white-noise component, and a synthetic frequency-dependent channel. A known noise-only reference is also generated and passed to the oracle processor. The probe is not recorded speech and does not reproduce realistic phonetic content, room acoustics, or an auditory system.

### 3.3 Reference algorithms

1. **Identity:** return the degraded mixture unchanged.
2. **Fixed profile EQ:** apply the inverse synthetic attenuation curve, with a 12 dB maximum boost.
3. **Adaptive oracle Wiener-style processor:** multiply the capped profile compensation by a frequency-wise Wiener-style mask estimated using the independent noise-only reference.

The oracle reference is intentionally idealized. It makes the experiment useful for checking a best-case masking path but prevents the algorithm from being interpreted as a deployable estimator.

### 3.4 Metrics

SNR and SI-SDR are calculated against the known synthetic target over the active probe interval. Both are signal-fidelity metrics. Neither is treated as a direct measure of speech intelligibility or human hearing benefit.

### 3.5 Reproducibility

The implementation records the root seed, deterministic trial seeds, package versions, condition identifiers, and per-trial metrics. pytest checks profile validation, a noiseless compensation property, finite and length-preserving adaptive output, benchmark repeatability, and invalid parameter handling. A GitHub Actions workflow runs tests on Python 3.10–3.12.

## 4. Results

A reference run was executed with root seed 20261124 and ten repeats in each profile × input-SNR cell. This yielded 90 synthetic trials and 270 algorithm-level rows. The Python, NumPy, and SciPy versions and all individual scores are preserved in artifacts/reference-run/summary.json.gz and artifacts/reference-run/trial_results.csv.gz.

Table 1 reports pooled descriptive SI-SDR results across the three synthetic profiles at each nominal input-SNR level. Each cell contains 30 trial scores (3 profiles × 10 repeats). The standard deviation is the sample standard deviation across those trials; it is descriptive and does not represent uncertainty over a human population.

| Nominal input SNR | Identity SI-SDR, mean ± SD (dB) | Fixed profile EQ SI-SDR, mean ± SD (dB) | Adaptive oracle Wiener SI-SDR, mean ± SD (dB) |
|---:|---:|---:|---:|
| 0 dB | 2.523 ± 5.770 | 0.170 ± 0.242 | 12.580 ± 0.151 |
| 10 dB | 11.562 ± 5.135 | 10.171 ± 0.251 | 19.598 ± 0.072 |
| 20 dB | 17.706 ± 3.078 | 20.168 ± 0.243 | 24.358 ± 0.042 |

The oracle Wiener condition scores highest in this simulator, which is consistent with it being given an independent noise-only reference. This result must not be interpreted as a fair comparison with deployable methods. Fixed profile EQ did not dominate identity processing in the 0 dB condition, illustrating that boosting the inverse channel can also boost noise. Results are specific to the synthetic harmonic probe, the three generated profiles, and the simulator's exact assumptions.

No inferential statistics are planned for repeated synthetic seeds. These values are descriptive summaries of this configured simulator and do not establish speech intelligibility or hearing benefit.

## 5. Discussion

The benchmark can test whether the code behaves consistently under a known synthetic channel, whether fixed equalization counteracts the configured attenuation, and how an idealized noise mask changes signal-fidelity metrics. The setup is intentionally transparent and limited. The oracle algorithm has access to information that ordinary deployment systems do not possess. The fixed equalizer also assumes the correct channel profile is known exactly.

The project does not claim algorithmic novelty relative to openMHA, DAL, commercial self-fitting hearables, or auditory-model-in-the-loop research. A stronger contribution would require a matched implementation and evaluation against relevant baselines, recorded speech/noise data, speaker-disjoint splits, appropriate intelligibility measures, ablations, runtime measurements, and independent domain review.

## 6. Limitations and safety

The synthetic probe is not speech. The simulator is not a cochlear or hearing-loss model. No human participants, audiograms, calibrated headphones, ear-canal measurements, or subjective tests are included. The algorithmic gain cap is not a sound-pressure safety limit. The work is not a hearing test, hearing aid, medical device, or clinical study. No conclusions about diagnosis, treatment, speech understanding, comfort, or hearing benefit can be drawn.

## 7. Conclusion

Aurelius v0.2.0 provides a deterministic and inspectable software benchmark for a narrow class of profile-aware audio-processing experiments. The value of this release is in reproducibility, explicit assumptions, raw machine-readable outputs, and automated tests—not a claim to have invented personalized hearing assistance. Future work should prioritize fair openMHA comparisons, carefully scoped recorded-speech evaluation, and expert review before any broader research claim.
