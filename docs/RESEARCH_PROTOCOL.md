# Research protocol: Aurelius synthetic benchmark v0.2.0

## Objective

Evaluate whether the reference implementations behave as expected under a known, synthetic frequency-dependent channel and reproducible additive noise. This protocol validates software behaviour and controlled signal processing only.

## Research question

For a known synthetic channel attenuation curve, how do (1) no processing, (2) fixed capped inverse-profile equalization, and (3) profile equalization multiplied by an oracle Wiener-style mask compare on SNR and SI-SDR against the known synthetic target?

## Hypotheses

- H1 (implementation check): fixed profile equalization should reduce reconstruction error relative to identity processing in a noiseless, correctly specified synthetic channel, subject to STFT boundary effects and gain caps.
- H2 (trade-off): fixed profile equalization may amplify noise as well as target energy, so it is not expected to dominate every noisy condition.
- H3 (oracle experiment): an ideal noise-reference mask may improve signal fidelity in some noisy conditions, but the effect is condition-dependent and should be reported rather than assumed.

These are engineering hypotheses, not hearing or clinical hypotheses.

## Experimental design

- Sample rate: 16 kHz mono.
- Probe: deterministic synthetic harmonic signal with slow amplitude modulation. It is not recorded speech.
- Channel: deterministic STFT-domain attenuation interpolated from three synthetic frequency/attenuation profiles.
- Noise: seeded independent white Gaussian noise at nominal input SNRs of 0, 10, and 20 dB.
- Algorithms: identity, fixed profile EQ, and adaptive profile EQ with an independent noise-only reference.
- Repeats: command-line configurable; default three repeats per profile/SNR cell.
- Randomization: seeds are deterministically derived from the configured root seed, profile, condition, and repeat.
- Outputs: per-trial CSV and grouped JSON with means and population standard deviations.

Default full design: 3 profiles × 3 input-SNR conditions × 3 repeats = 27 trials; 81 algorithm-level output rows.

## Algorithms and assumptions

### Identity
The degraded mixture is returned unchanged.

### Fixed profile equalization
The known synthetic attenuation curve is inverted and capped at 12 dB. This is a simple DSP baseline only. It does not implement NAL-NL2, DSL, multichannel compression, real-ear verification, or a clinical prescription.

### Adaptive oracle Wiener-style processor
A Wiener-style frequency mask is estimated from an independent noise-only reference generated by the simulator and then multiplied by the capped profile compensation. Because a perfect noise-only reference is supplied, this is an oracle experiment / upper-bound reference, not a realistic deployable estimator. The same assumptions must be preserved in any interpretation.

## Metrics

- SNR (dB): ratio of reference energy to squared reconstruction error.
- SI-SDR (dB): scale-invariant signal-to-distortion ratio after mean removal.

These are signal-fidelity metrics against a known synthetic reference. They are not speech-intelligibility scores and cannot establish perceived benefit, comfort, safety, or clinical efficacy.

## Analysis plan

- Report every algorithm × profile × input-SNR cell.
- Report the number of trials, mean, and standard deviation.
- Preserve raw per-trial rows for inspection.
- Do not run significance tests or make population-level claims from synthetic repeated seeds.
- Include failure conditions and all parameter changes.
- Re-run with a fixed root seed to verify repeatability.

## Exclusions and limitations

- No human participants or personally identifying information.
- No calibrated playback hardware, ear-canal measurements, or real audiograms.
- No real speech corpus, speakers, room impulse responses, or competing talkers.
- No physiological cochlear model.
- The simulator knows the channel profile used to generate the signal; this is an oracle assumption.
- The synthetic probe is deliberately limited and cannot represent the variability of human speech or hearing impairment.
- STFT reference processing is offline; no real-time latency claim is made.

## Extension protocol for a future study

1. Select public speech/noise datasets and verify licensing, provenance, and permitted uses.
2. Establish a matched evaluation pipeline and report dataset splits, speakers, environments, and preprocessing.
3. Add objective speech metrics appropriate to the dataset and research question; do not interpret any single metric as clinical benefit.
4. Reproduce openMHA with a documented configuration. If DAL code is available, document commit, dependencies, hardware, and exact training/inference details before comparison.
5. Add ablations and runtime/latency measurements on named hardware.
6. Have an audiologist and auditory-signal-processing researcher review the protocol and interpretation.
7. Any human-subject listening study requires appropriate ethics approval, informed consent, trained supervision, and calibrated equipment before recruitment or data collection.
